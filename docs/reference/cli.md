# CLI reference

Generated by `python scripts/gen_cli_reference.py` from the argparse tree;
`tests/test_cli_reference.py` fails when this page is stale. Global options
go BEFORE the subcommand: `graphite --output-dir out build .`. A group's
commands (`graphite route reconcile`) are rendered under the group. Exit
codes are in `docs/reference/exit-codes.md`; configuration in
`docs/reference/configuration.md`.

## Global options

| Option | Meaning |
|---|---|
| `-h`, `--help` | show this help message and exit |
| `--version` | Print engine identity (version, fingerprint, cache version) and exit |
| `--output-dir` | Output directory (default: graph-out) |
| `--cache-dir` | Cache directory (default: .cache/graphite) |
| `--workers` | Parallel workers |
| `-v`, `--verbose` | Verbose logging |
| `--typescript-resolver` | TypeScript resolver mode (default: auto) (one of: `auto`, `compiler`, `heuristic`, `disabled`) |
| `--typescript-resolver-timeout` | TypeScript compiler resolver timeout in seconds |
| `--no-typescript-symbol-references` | Disable TypeScript compiler symbol-reference edges |
| `--llm` | Optional integration mode; canonical graph commands accept only none (one of: `none`, `auto`, `local`, `cloud`) |
| `--llm-provider` | Provider for explicit doctor/overlay operations; rejected by canonical commands |
| `--llm-model` | Model for explicit doctor/overlay operations |
| `--llm-base-url` | Provider base URL for explicit doctor/overlay operations |
| `--llm-api-key` | Provider key for explicit doctor/overlay operations; prefer a session-scoped environment value |
| `--llm-timeout` | Provider timeout for explicit doctor/overlay operations |
| `--llm-max-input-chars` | Maximum explicit overlay input characters |
| `--llm-max-output-tokens` | Maximum explicit overlay output tokens |
